# Corpus HOP v4.1 quick check

This bundle was generated from the new corpus-derived HOP builder using the demo fallback because no BabyLM corpus path is present in the sandbox. It validates the format, gates, and audit artifacts. For the real BabyLM run, set `corpus.globs` to local BabyLM text and regenerate.

Open these first:

1. `dataset_report.md` — automatic gates and PASS/FAIL.
2. `example_sheet.md` — compact transformed examples.
3. `corpus_audit_sheet.md` — parser/audit examples and rejection reasons.
4. `samples/*_first20.jsonl` — raw records.
